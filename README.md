# Module 5: Stacks and Queues Laboratory

## Overview
This repository contains Python implementations of fundamental linear data structures—Stacks and Queues—built from first principles using both fixed-size arrays and dynamic singly linked lists[cite: 7].

## File Structure
- `array_stack.py`: Array-based stack implementation with overflow and underflow exception handling[cite: 7].
- `linked_stack.py`: Singly linked list stack implementation operating at the head[cite: 4, 7].
- `array_queue.py`: Circular array-based queue using modulo arithmetic[cite: 6, 7].
- `linked_queue.py`: Linked list queue maintaining head and tail references[cite: 6, 7].
- `main.py`: Interactive menu-driven test driver program[cite: 7].
- `applications.py`: Practical applications including a balanced parentheses checker and a print queue simulation[cite: 7].
- `analysis.md`: Written analysis addressing design trade-offs[cite: 8].
