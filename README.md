# Module 5: Stacks and Queues Laboratory

 Overview
This repository contains Python implementations of fundamental linear data structures—Stacks and Queues—built from first principles using both fixed-size arrays and dynamic singly linked lists.

File Structure
array_stack.py: Array-based stack implementation with overflow and underflow exception handling.
linked_stack.py: Singly linked list stack implementation operating at the head.
array_queue.py: Circular array-based queue using modulo arithmetic.
linked_queue.py: Linked list queue maintaining head and tail references.
main.py: Interactive menu-driven test driver program.
applications.py: Practical applications including a balanced parentheses checker and a print queue simulation.
analysis.md: Written analysis addressing design trade-offs.

How to Run
Execute the interactive test driver:
bash
python main.py
